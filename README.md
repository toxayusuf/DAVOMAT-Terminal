# DAVOMAT Terminal

Веб-терминал учёта прихода и ухода сотрудников DAVOMAT.

## Рабочий сценарий

1. На экране две большие кнопки: **КЕЛДИ** и **КЕТДИ**.
2. Камера в режиме ожидания выключена.
3. После нажатия кнопки камера включается только на время распознавания.
4. После успешной отметки камера автоматически выключается.
5. Регистрация лица запускается из админки; сотрудник видит кольцевой прогресс вокруг лица и двигает головой до завершения.

Backend: Google Apps Script + Google Sheets + Google Drive.

В репозитории нет биометрических данных сотрудников и нет токена терминала.

Версия клиента: **v0.6.1**.
