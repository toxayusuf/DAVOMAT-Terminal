## Зафиксированная архитектура
- Google Apps Script — backend и админка.
- Google Sheets — сотрудники, графики, посещения, зарплата, audit.

- GitHub Pages — только Face Terminal/PWA.

## UX
- Никакого ручного ввода Apps Script URL, device ID, device token или 6-значного кода сотрудником.
- Регистрация: админ нажимает `Юзни рўйхатга олиш` → терминал открывается сразу по реальному HTTPS URL → камера автоматически запускается → 6 качественных образцов → `ЮЗ ТАЙЁР`.
- Посещение: сотрудник нажимает только `КЕЛДИ` или `КЕТДИ` → камера → распознавание → запись события → камера выключается.
- Камера не работает постоянно.

## Точная причина about:blank в v0.8.2
Проблема была в самой админке: она сначала выполняла `window.open('about:blank')`, а затем пыталась асинхронно перенаправить это окно после нескольких вызовов `google.script.run`. В Apps Script/Chrome такая схема ненадёжна и в реальном тесте оставила пустую вкладку `about:blank`.

## Исправление v0.8.3
- Полностью убрано открытие `about:blank`.
- Настройки терминала (`TERMINAL_PUBLIC_URL`, `DEVICE_ID`, `DEVICE_TOKEN`, `WEB_APP_URL`) загружаются сразу при входе в админку до показа рабочего интерфейса.
- По клику `Юзни рўйхатга олиш` новая вкладка сразу открывается на `https://toxayusuf.github.io/DAVOMAT-Terminal/` с автоматической конфигурацией в URL fragment.
- После открытия терминала Apps Script создаёт enrollment-сессию; терминал уже опрашивает `pendingEnrollment` и автоматически запускает регистрацию, как только сессия появляется.
- Для текущего deployment добавлен резервный WEB_APP_URL, поэтому отсутствие `WEB_APP_URL` в старом backend больше не блокирует запуск.
- Code.gs менять не требуется.
