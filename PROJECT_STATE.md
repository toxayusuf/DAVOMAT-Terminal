## Текущая проблема / диагностика
- v0.6.5 Admin.html принимает правильный PIN, но основной интерфейс не открывается.
- Скриншоты показали две независимые причины: HTML/backend могли быть разных версий (publicAdminPing отсутствовал в backend), а основной UI-скрипт находился после внешнего синхронного QR-скрипта и не инициализировался до входа.
- v0.6.6 устраняет оба риска: один login-controller, без publicAdminPing, QR-библиотека грузится лениво только при привязке терминала, login/load ошибки показываются точно.
- Admin.html v0.6.6 совместим с backend v0.6.4+.
