# DAVOMAT — PROJECT STATE

Версия: v0.8.2
Дата: 2026-09-16

## Зафиксированная архитектура
- Google Apps Script — backend и админка.
- Google Sheets — сотрудники, графики, посещения, зарплата, audit.
- Google Drive — контрольные фотографии.
- GitHub Pages — только Face Terminal/PWA.

## UX
- Никакого ручного ввода Apps Script URL, device ID, device token или 6-значного кода сотрудником.
- Регистрация: админ нажимает `Юзни рўйхатга олиш` → открывается терминал → камера автоматически запускается → 6 качественных образцов → `ЮЗ ТАЙЁР`.
- Посещение: сотрудник нажимает только `КЕЛДИ` или `КЕТДИ` → камера → распознавание → запись события → камера выключается.
- Камера не работает постоянно.
- Passive liveness / anti-spoof, контрольное фото и offline queue сохранены.

## Причина сбоя 16.09
Настройка Web App была правильной: `Execute as me` + `Anyone/Все`. Сбой был не в доступе Google. Терминал v0.8.x ожидал новый `api=provision`, а текущий backend Apps Script оставался совместимым со старым протоколом терминала. Поэтому повторное изменение deployment access ничего не меняло.

## Исправление v0.8.2
- Временный pairing через `?backend=&pair=` больше не нужен для текущего рабочего теста.
- Админка передаёт терминалу конфигурацию автоматически в URL fragment (`#cfg`), который не отправляется GitHub или стороннему серверу.
- Терминал уже умеет читать этот формат.
- Enrollment code передаётся автоматически в query, сотрудник его не видит и не вводит.
- Новый flow не требует изменений `Code.gs` и не зависит от endpoint `api=provision`.
- Popup открывается синхронно по клику, чтобы Chrome не блокировал камеру/новую вкладку после асинхронного Apps Script вызова.
