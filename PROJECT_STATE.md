# DAVOMAT — PROJECT STATE

Версия: v0.8.0
Дата: 2026-09-15

## Зафиксированная архитектура
- Google Apps Script — backend и админка.
- Google Sheets — сотрудники, графики, посещения, зарплата, audit.
- Google Drive — контрольные фотографии.
- GitHub Pages — только Face Terminal/PWA.

## UX v0.8.0
- В Face Terminal больше нет ручного ввода Apps Script URL, device ID или device token.
- Устройство привязывается одноразовой ссылкой от админки; секрет сохраняется локально.
- Регистрация лица: админ нажимает `Юзни рўйхатга олиш` → камера открывается автоматически → 6 качественных образцов → `ЮЗ ТАЙЁР`.
- Ходим: нажимает только `КЕЛДИ` или `КЕТДИ` → камера включается → лицо распознаётся → событие записывается → камера выключается.
- Камера не работает постоянно.
- Passive liveness / anti-spoof, контрольное фото, offline queue сохранены.

## Исправлено в v0.8.0
- Убрана страница `Биринчи созлаш` с ручными техническими полями.
- Исправлена реальная рассинхронизация репозитория: index.html был v0.7.1, а app.js оставался v0.6.1.
- Новый app.js сохраняет обратную совместимость с `#cfg` ссылкой текущей админки v0.7.1, поэтому чистый тест регистрации можно продолжить без очередного изменения Apps Script.
- Для следующего Apps Script deployment добавлено одноразовое pairing-подтверждение: device token больше не нужен в обычной ссылке.
- Удалён лишний `auto-enroll.js`; вся логика регистрации теперь в одном app.js.
- Service Worker cache поднят до v0.8.0, чтобы не подхватывались старые версии терминала.
- При новой enrollment-сессии в Apps Script v0.8.0 старые OPEN-сессии для этого терминала отменяются.

## Текущий тест
- В базе есть тестовый сотрудник `тест` / `доктор`.
- GitHub Pages v0.8.0 опубликован успешно.
- С текущей админкой v0.7.1: закрыть старую вкладку терминала, снова нажать `Юзни рўйхатга олиш` → `Камерани очиш ва рўйхатга олиш`; новая вкладка должна показывать v0.8.0 и автоматически открыть камеру без ручных полей.

## Важное
Если GitHub Terminal v0.8.0 пишет, что сервер недоступен, проверить deployment Apps Script: `Execute as me` и доступ `Anyone`. Это единственная инфраструктурная настройка, которую нельзя изменить из кода терминала.
